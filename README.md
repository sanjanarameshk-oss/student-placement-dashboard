# Student Placement Dashboard

A React-based Student Placement Dashboard designed to help students manage placement opportunities, job applications, interviews, profiles, and placement notifications.

## 🚀 Live Demo

http://localhost:5173/

## 📌 Project Features

* Student Login and Registration
* Student Profile Management
* Placement Dashboard
* Job Openings
* Search and Filter Jobs
* Apply for Jobs
* Track Job Applications
* Interview Schedule
* Selection Status
* Placement Statistics
* Notifications
* Responsive Design

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* React Router
* Context API
* React Hooks
* Local Storage
* Vite

## 🎯 Project Objective

The main objective of this project is to provide a simple and user-friendly platform where students can view placement opportunities, apply for jobs, track applications, check interviews, and monitor their placement progress.

## 📊 Main Modules

### Dashboard

Displays application statistics, placement updates, and latest job opportunities.

### Job Openings

Students can search, filter, view, and apply for available jobs.

### My Applications

Students can track their applied jobs and application status.

### Interview Schedule

Displays scheduled interviews for selected applications.

### My Profile

Students can update their personal and academic information.

### Notifications

Displays interview alerts, company updates, and placement announcements.
